# Student To-Do List

A beginner-friendly student project built with **HTML, CSS, and JavaScript**. Organize homework, assignments, revision, and exam preparation in one simple page.

## Features
- Add tasks with an optional subject and due date
- Mark tasks as completed or active
- Filter tasks by All, To do, and Completed
- Delete individual tasks or clear all completed tasks
- Automatically save tasks in browser local storage
- Responsive layout for mobile and desktop
- Accessible form labels and keyboard focus styles

## Run the project
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add a task and refresh the page to see that tasks are saved locally.

No installation or server is required.

## Project files
- `index.html` — page structure and form
- `style.css` — responsive styling
- `script.js` — task actions, filters, and local storage

## Learning goals
Practice semantic HTML, CSS layout, DOM manipulation, event listeners, arrays and objects, and browser local storage.
